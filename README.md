# Kejutan Ulang Tahun untuk Nova Virgie 💗

Website ucapan ulang tahun sederhana berbahasa Indonesia, dibuat dengan HTML, CSS, dan JavaScript.

## Menjalankan secara lokal
Buka `index.html` di browser. Untuk pengembangan, disarankan memakai ekstensi Live Server di VS Code.

## Deploy ke GitHub dan Vercel
1. Buat repository baru di GitHub.
2. Unggah seluruh isi folder proyek ini ke repository (jangan unggah folder `.git` lama).
3. Masuk ke [Vercel](https://vercel.com/) dan pilih **Add New → Project**.
4. Import repository GitHub yang baru dibuat.
5. Framework Preset pilih **Other**. Biarkan Build Command dan Output Directory kosong/default karena ini website statis.
6. Klik **Deploy**. Halaman utama otomatis menggunakan `index.html`.

## Mengganti foto
Ganti file `d1.jpg` dengan foto pilihanmu dan pertahankan nama file `d1.jpg`. Website hanya memakai satu foto yang sama di halaman terakhir.

## Struktur
- `index.html` — halaman pembuka
- `cause.html` — pesan-pesan kejutan
- `last.html` — ucapan penutup
- `d1.jpg` — satu-satunya foto
- `gif1.gif`, `gif2.gif` — animasi dekoratif
